# 🤖 AI Resume Screening System

An AI-powered Resume Screening System that automatically analyzes resumes, predicts suitable job roles, calculates ATS match scores, extracts skills, and helps recruiters shortlist candidates.

---

## 🚀 Features

✅ Resume PDF Upload  
✅ AI Based Job Role Prediction  
✅ NLP Resume Analysis  
✅ ATS Match Percentage Calculation  
✅ Skill Extraction  
✅ Missing Skill Detection  
✅ Experience Detection  
✅ Candidate Selection (Selected / Rejected)  
✅ SQLite Database Integration  
✅ Admin Login System  
✅ Candidate Dashboard
